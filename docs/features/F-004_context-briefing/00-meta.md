# Meta

## Overview

SAALCO v1.2 実装指示書 §3 の順1。承認点でセッションを切って文書から再開する運用（規則 3.5）を、ツールで支える。

- `saalco approve` が、承認の完了時に「次の工程は新しいセッションで始めること」と、再開に使うコマンドを表示する（実装指示書 §4.1）。
- 新しいコマンド `saalco context <F-nnn>` が、新しいセッションのエージェントが最初に読むブリーフィングを、決定論的に出力する（実装指示書 §4.2・§4.3）。

問いカードに関する出力（実装指示書 §4.2 の 5・6）は、問いカードの Feature（実装指示書 §3 の順2）で追加する。この Feature では扱わない。

新しいモジュール `saalco.context` を加え、`saalco.commands`（approve）と `saalco.cli` を変更する。複数のモジュールにまたがり、CLI にコマンドを1つ加える（既存のコマンドの入出力の互換性は保つ）ため、Tier M とする（F-003 と同じ考え方）。
